# Первый проект в AI-Demo: создаём и видим в галерее
*Для новичков, займёт около 30 минут.*

Если вы склонировали `AI-Demo`, запустили `npm run dev`, увидели галерею, но не понимаете, откуда здесь берутся проекты и как добавить свой — этот гайд для вас. Оболочка сама по себе пустая: всё, что вы видите в каталоге, лежит в папке `projects/`. Пока там нет вашей папки, в галерее нечего показывать.

За 30 минут мы создадим папку проекта,напишем простойй `index.html`, заполним `project.yaml` и увидим результат в боковом меню. В конце вы откроете свой проект на весь экран и убедитесь, что он в изолированной песочнице: его стили не ломают оболочку, а стили оболочки не влияют на ваш проект.

## Что понадобится
- Node.js версии 18 или выше и npm.
- Склонированный репозиторий `AI-Demo`.
- Установленные зависимости (если вы ещё этого не делали, выполните `npm install` в корне репозитория).
- Запущенный dev-сервер: `npm run dev` (URL обычно `http://localhost:5173`).
- 30 минут свободного времени.

> **Совет:** не закрывайте терминал с `npm run dev`, пока работаете. Vite автоматически подхватывает новые файлы в `projects/`, перезапускать сервер не нужно.

## Шаг 1. Создайте папку проекта
1. Откройте терминал в корне репозитория `AI-Demo`.
2. Перейдите в папку с проектами: `cd projects`.
3. Создайте папку с коротким именем на латинице, без пробелов. Например: `mkdir my-first-demo`.

**Вы должны увидеть:** в папке `projects/` появилась новая директория `my-first-demo` рядом с уже существующими проектами галереи.

<details>
<summary>Почему имя папки лучше писать латиницей</summary>
Имя папки становится частью адреса проекта в галерее. Кириллица и пробелы в URL превращаются в длинные последовательности вида `%D0%...`, и ссылку потом неудобно копировать. Латинское имя в нижнем регистре через дефис — самый предсказуемый и надёжный вариант.
</details>

## Шаг 2. Напишите index.html
1. Внутри `projects/my-first-demo/` создайте файл `index.html`.
2. Вставьте в него минимальную страницу с видимым результатом:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>My First Demo</title>
  <style>
    body {
      font-family: sans-serif;
      background: #1a1a2e;
      color: #e0e0e0;
      display: grid;
      place-items: center;
      height: 100vh;
      margin: 0;
    }
    h1 { font-size: 2rem; }
  </style>
</head>
<body>
  <h1>Привет!</h1>
</body>
</html>
```

**Вы должны увидеть:** файл `index.html` успешно создан в папке `projects/my-first-demo/` и содержит указанный выше код.

## Шаг 3. Заполните project.yaml
1. В той же папке `projects/my-first-demo/` создайте файл `project.yaml`.
2. Впишите в него обязательные поля:

```yaml
name: "My First Demo"
summary: "Мой первый проект в галерее AI-Demo"
status: "experimental"
tags: ["demo", "first"]
```

3. Сохраните файл и посмотрите на терминал, где запущен `npm run dev`.

**Вы должны увидеть:** в терминале появилось сообщение о пересборке (например, `[vite] manifest updated` или аналогичное информационное сообщение), а процесс `npm run dev` продолжает работать без красных строк ошибок.

## Шаг 4. Найдите проект в галерее
1. Переключитесь в браузер с открытой галереей.
2. Обновите страницу: нажмите `F5` или `Ctrl+R`.
3. В левом боковом меню найдите пункт «My First Demo». Если список длинный, начните вводить `my` в поле поиска.

**Вы должны увидеть:** в боковом меню появился пункт «My First Demo», а в основной области — превью с заголовком «Привет из песочницы!» на тёмно-синем фоне.

## Шаг 5. Откройте проект на весь экран
1. Кликните по «My First Demo» в боковом меню.
2. В правом верхнем углу нажмите кнопку полноэкранного режима (иконка развёртывания).

**Вы должны увидеть:** ваш проект занимает весь экран, заголовок «Привет из песочницы!» стоит по центру на тёмно-синем фоне. При нажатии кнопки выхода вы возвращаетесь в галерею, и оболочка выглядит как раньше (ваш `body { background: #1a1a2e }` не перекрасил интерфейс галереи).

---

> ⚠️ **Если на шаге 3 сборка упала или проект не появился в меню:** почти всегда дело в опечатке в `project.yaml`. Я разобрал самые частые случаи отдельно: [Сборка падает с ошибкой в project.yaml: что делать](sborka-padaet-oshibka-project-yaml.md).

## Итог
Всё, проект готов и виден в галерее.

По пути вы прошли базовый цикл работы с AI-Demo: создать папку → написать точку входа → заполнить метаданные → увидеть результат. Дальше будет то же самое, только проекты сложнее, а песочница так же надёжно изолирует их друг от друга.

**Что вы теперь умеете:**
- [x] создавать папку проекта в `projects/`
- [x] писать точку входа `index.html`
- [x] заполнять обязательные поля в `project.yaml`
- [x] находить свой проект в галерее и открывать его на весь экран
