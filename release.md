# AI-Demo 1.1.0: три новые аркадные песочницы и адаптивный полноэкранный режим
27 октября 2025 · [Релиз на GitHub](https://github.com/Starbugstone/AI-Demo/releases/tag/1.1.0) · [Полный список изменений](changelog.md)

## Главное
В галерее AI-Demo появились три новые интерактивные песочницы для экспериментов с кодом:
- **Neon Pipelines**: клон Flappy Bird с неоновой стилистикой.
- **Cascade Candy Clash**: match-three головоломка с цепными реакциями, бомбами и радужными взрывами.
- **Minesweeper**: классический «Сапёр», готовый к вашим модификациям.

Теперь вы можете не только изучать структуру проектов, но и сразу взаимодействовать с результатом, не выходя из оболочки.

## Что ещё
- **Адаптивный полноэкранный режим**. Песочницы теперь корректно масштабируются под любой размер экрана, а предпросмотр больше не «ломается» при разворачивании на весь экран.
- **Улучшенные эффекты в match-three**. Добавлены визуальные подсказки (hinting), переработаны анимации взрывов и добавлено звуковое сопровождение для более динамичного геймплея.

## Перед обновлением
Ничего менять не нужно. Конфигурация осталась полностью обратной совместимой. Если вы запускаете проект локально, рекомендуется обновить зависимости, так как некоторые неиспользуемые пакеты были удалены для ускорения сборки.

## Обратите внимание
- В проекте **Aurora** исправлена критическая ошибка, из-за которой `RequestAnimationFrame` вызывался без привязки к `window`. Если вы изучали или модифицировали его код, теперь он работает стабильно в любом окружении.
- Для корректной работы в Azure Static Web Apps были обновлены версии npm. Убедитесь, что вы используете актуальную версию Node.js.

## Как обновиться
Если вы работаете с локальной копией репозитория:
```bash
git pull
npm install
npm run dev
```
