# Shadow DOM-песочница

## Что это

Песочница — это правило, по которому AI Demo Playground запускает каждый эксперимент
в своём отдельном уголке одной страницы. Проще говоря: договорённость о том, как
пустить на одну страницу много чужого кода так, чтобы он не мешал ни общему
интерфейсу, ни соседним экспериментам.

Уголок строится из отдельного набора элементов страницы — такого же дерева, какое
браузер показывает обычному сайту, только спрятанного от остальной страницы.
Такое дерево называется shadow root. Стили и скрипты внутри него не пересекаются
с тем, что находится снаружи.

Каждый эксперимент живёт в своей папке `projects/имя/` и состоит из `index.html`
и файла с описанием `project.yaml`.

## Зачем нужно

Все эксперименты открываются в одной вкладке: пользователь выбирает проект в и он появляется рядом с навигацией. Если запускать их в общем дереве страницы,
они начнут мешать друг другу. Один проект задаёт красный цвет для всех кнопок —
и краснеет меню, другой вешает обработчик клика на всю страницу — и ловит нажатия,
которые предназначались навигации.

Можно было бы запускать каждый эксперимент в отдельном окне
с собственной страницей. Изоляция была бы полной, но навигация, поиск и хлебные
крошки перестали бы работать одинаково для всех проектов: каждый жил бы сам по себе.

Shadow DOM даёт компромисс: стили и запросы к элементам изолированы, а сама страница
остаётся одной. Поэтому поиск по каталогу и полноэкранный режим работают для любого
эксперимента без особых настроек.

## Как устроено

Песочница состоит из трёх частей:

- отдельное дерево элементов внутри страницы — shadow root,
- код самого эксперимента — HTML, стили и JavaScript из его папки,
- обёртка, которая следит за тем, что эксперимент создаёт: таймеры, обработчики
  событий, циклы анимации.

Когда пользователь выбирает проект, оболочка читает его `index.html`, переносит
разметку внутрь shadow root и запускает скрипты через обёртку. Пока проект открыт,
обёртка записывает всё, что тот создал. При переходе к другому проекту оболочка
убирает старый уголок и отменяет всё записанное — таймеры, слушатели, анимации.
Иначе старый эксперимент продолжал бы работать в фоне, хотя его уже не видно.

Отсюда следует неочевидное поведение: **скрипт проекта не видит остальную страницу**.
Поиск элемента по имени класса находит его только внутри песочницы — боковая панель
и хлебные крошки для него не существуют. Это цена изоляции: обычный HTML-код,
который обращается ко всей странице, внутри песочницы работает не так, как ожидалось.
У проекта есть свой корень, и обращаться нужно к нему.

## Как связано с остальным

Песочница — центральное понятие для всего приложения. От неё зависят:

- **`project.yaml`** — по его полям оболочка понимает, какой файл загружать и как
  подписать эксперимент в каталоге;
- **каталог и поиск** — список проектов собирается из файлов описания, и именно
  из него песочница получает точку входа;
- **навигация и полноэкранный режим** — живут снаружи песочницы и не меняются
  при переключении экспериментов.

Понятие не связано со сборкой и деплоем: Vite просто копирует папку `projects/`
в `dist/`, и изоляция работает одинаково в разработке и на опубликованном сайте.
