# AI Demo Playground

Галерея AI-экспериментов и интерактивных UI-проектов, собранная в виде одностраничного приложения на Vue 3. Основная оболочка управляет навигацией и изолированно запускает каждый мини-проект через Shadow DOM, предотвращая конфликты стилей и скриптов. Подойдёт для демонстрации интерактивных прототипов и быстрого развёртывания на платформах вроде Azure Static Web Apps.

## Возможности

- **Изоляция без iframe:** Запуск standalone HTML/JS проектов внутри Shadow DOM с автоматической очисткой ресурсов при уходе со страницы.
- **Автоматический манифест:** Метаданные каждого проекта описываются в файле `project.yaml`, общий каталог собирается Vite-плагином автоматически.
- **Удобная навигация:** Поиск и фильтрация проектов в реальном времени по названию, тегам и AI-агентам.
- **Полноэкранный режим:** Возможность развернуть любую песочницу на весь экран для детального просмотра.
- **Готовность к деплою:** Оптимизированная сборка в папку `dist/` для публикации прямо из GitHub.
- **Простой стек:** Vue 3 + Vite, чистый JavaScript без TypeScript.

## Требования

- Node.js версии 18 или новее
- npm или другой совместимый пакетный менеджер (yarn, pnpm)
- Современный веб-браузер (Chrome, Firefox, Safari, Edge)
- Около 50 МБ свободного места на диске

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/Starbugstone/AI-Demo.git
   cd AI-Demo
   ```

2. Установите зависимости
    ```
      npm install
    ```

3. Запустите локальный сервер 
    ```
       npm run dev
    ```

4. Откройте в браузере URL, который будет выведен в терминале (обычно http://localhost:5173).

## Пример использования

Запустить сервер разработки:

   ```
   npm run dev
   ```

Собрать проект для продакшена:
   ```
   npm run build
   ```

Вывод:
   ```
   > ai-demo@1.0.0 build
   > vite build
   dist/ ready in 450 ms.
   ```

Предпросмотр собранной версии:
   ```
   npm run preview
   ```

Собранные файлы находятся в папке `dist/`
